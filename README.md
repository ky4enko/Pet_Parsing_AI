# Pet_Parsing_AI — AUTO.RIA Car Price Analyzer

Десктопное приложение для поиска автомобилей на AUTO.RIA, сбора информации об объявлениях и анализа рыночной стоимости с помощью искусственного интеллекта.

## Возможности

### Поиск автомобилей

Приложение поддерживает два направления поиска:

- **ДВС / Гибрид** — поиск автомобилей с бензиновыми, дизельными и гибридными двигателями.
- **Электромобили** — поиск автомобилей с электрическими двигателями.

### Фильтрация объявлений

В зависимости от типа автомобиля можно задавать параметры поиска:

- Марка и модель автомобиля.
- Год выпуска.
- Пробег.
- Тип топлива.
- Объём двигателя.
- Коробка передач.
- Тип привода.

Для электромобилей предусмотрен отдельный сценарий поиска.

### Сбор и обработка данных

Приложение взаимодействует с AUTO.RIA API, получает объявления и загружает подробную информацию об автомобилях.

Данные обрабатываются и преобразуются в единый формат для дальнейшего использования.

### AI-анализ

Для анализа собранных объявлений используется OpenAI API.

AI помогает оценить рыночную ситуацию и сформировать аналитическую информацию на основе найденных автомобилей.

### Пользовательский интерфейс

- Десктопный интерфейс на PySide6.
- Библиотека PyQt-Fluent-Widgets.
- Разделение поиска автомобилей с ДВС и электромобилей.
- Страница отображения результатов поиска.
- Настройка внешнего вида приложения.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <REPOSITORY_URL>
cd Pet_Parsing_AI
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
```

### 3. Активация окружения

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

Заполните необходимые API-ключи согласно шаблону `.env.example`.

Для работы приложения необходим доступ к AUTO.RIA API. Для AI-анализа также требуется API-ключ OpenAI.

**Важно:** файл `.env` содержит конфиденциальные данные и не должен попадать в GitHub.

### 6. Запуск приложения

```powershell
python -m app.ui.main_window
```

## Безопасность

- API-ключи хранятся в локальном файле `.env`.
- `.env` исключён из Git через `.gitignore`.
- Для настройки окружения используется `.env.example`.

Не публикуйте реальные API-ключи и другие секретные данные в открытом репозитории.
