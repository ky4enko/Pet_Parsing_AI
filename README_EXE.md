# AUTO.RIA Analyzer --- нормальный сборщик

## В этой версии

-   `.env` копируется целиком, побайтно, без удаления и изменения строк.
-   Проверяется SHA256 исходного `.env` и его копий.
-   Все 6 файлов ресурсов копируются в папку приложения и внутрь
    `_internal` (если используется PyInstaller 6).
-   Добавлен runtime hook: он загружает полный `.env` до запуска кода
    приложения.
-   Создаётся ярлык **AUTO.RIA Analyzer** с новой синей иконкой.
-   Если EXE уже существует, скрипт **не запускает PyInstaller
    повторно**: он исправляет комплектность существующей сборки и
    запускает её.
-   Если EXE отсутствует, выполняется полноценная компиляция.

## Как запустить

1.  Распакуй **все файлы** из архива прямо в `E:\Pet_Parsing_AI`.

2.  Подтверди замену `build_pet_parsing_ai.ps1` и
    `AUTO_RIA_Analyzer.ico`, если Windows спросит.

3.  Дважды щёлкни `BUILD_AUTO_RIA_ANALYZER.bat`.

    Либо открой PowerShell и выполни:

    ``` powershell
    cd E:\Pet_Parsing_AI
    .\build_pet_parsing_ai.ps1
    ```

После завершения приложение откроется автоматически. В дальнейшем
запускай его с рабочего стола через ярлык **AUTO.RIA Analyzer**.

## Важно

-   Исходный `E:\Pet_Parsing_AI\.env` не изменяется.
-   В папку `dist\Pet_Parsing_AI` копируется полная копия `.env` без
    изменения содержимого.
-   Внутри приложения будет находиться копия всех переменных из `.env`,
    включая секреты. Это предназначено только для личного использования
    на твоём компьютере. **Не отправляй эту сборку другим людям.**
-   Скрипт не удаляет резервные предыдущие сборки и не затрагивает базу
    данных.
